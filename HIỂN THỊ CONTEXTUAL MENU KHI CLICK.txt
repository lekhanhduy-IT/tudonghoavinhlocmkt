HIỂN THỊ CONTEXTUAL MENU KHI CLICK VÀO TEXT LAYER VÀ IMAGE LAYER TRÊN CANVAS
======================================================================
0. THÊM
======================================================================
1. Sau khi đặt vào frame thì phải cho phép click 2 lần ảnh trong frame để hiện khung ảnh góc dưới frame để kéo căn chỉnh ảnh trong frame.
2. Thêm ô custom size width height canva chính trên toolbar.
3. Cho phép click vào ô text để sửa text,
4. Cho phép sửa trực tiếp nội dung trong khối html sau khi chèn vào canvas.
5. Cho phép hiện thêm thanh context menu
======================================================================
1. MỤC TIÊU
======================================================================

Xây dựng cơ chế nhận diện layer được người dùng click trên canvas và hiển thị bộ công cụ theo ngữ cảnh tương ứng với từng loại layer.

Hệ thống phải phân biệt tối thiểu hai loại layer:

1. Text layer.
2. Image layer.

Khi người dùng click chuột trái vào một layer:

- Layer được đưa vào trạng thái selected.
- Hiển thị selection bounding box.
- Hiển thị các resize handle phù hợp.
- Hiển thị contextual floating toolbar gần layer.
- Thay đổi top editor toolbar theo loại layer.
- Đóng menu của layer trước đó.
- Cập nhật selection state.
- Không mở menu chuột phải mặc định của trình duyệt.

Lưu ý:

Trong đặc tả này, “context menu” được hiểu là contextual toolbar hoặc contextual action menu xuất hiện khi người dùng click chọn layer, không nhất thiết là menu được mở bằng chuột phải.

5. ĐĂNG KÝ SỰ KIỆN CLICK TRÊN CANVAS
======================================================================

Nên dùng event delegation trên canvas container.

const canvasPage =
  document.getElementById("canvas-page");

canvasPage.addEventListener(
  "pointerdown",
  handleCanvasPointerDown
);

function handleCanvasPointerDown(event) {
  const layerElement =
    event.target.closest("[data-layer-id]");

  if (!layerElement) {
    clearSelection();
    return;
  }

  event.stopPropagation();

  const layerId =
    layerElement.dataset.layerId;

  const layerType =
    layerElement.dataset.layerType;

  selectLayer({
    layerId,
    layerType,
    layerElement,
    pointerEvent: event
  });
}

Nên sử dụng pointerdown thay vì click vì pointerdown:

- Phản hồi nhanh hơn.
- Dùng chung cho chuột, bút và màn hình cảm ứng.
- Có thể kết hợp với drag.
- Có thể phân biệt pointer type.
- Không phải chờ pointerup mới chọn layer.


======================================================================
6. HÀM SELECT LAYER
======================================================================

function selectLayer({
  layerId,
  layerType,
  layerElement,
  pointerEvent
}) {
  closeAllTransientMenus();

  editorState.selectedLayerIds = [
    layerId
  ];

  editorState.primaryLayerId =
    layerId;

  editorState.selectedLayerType =
    layerType;

  editorState.textEditMode = false;
  editorState.imageEditMode = false;

  removeSelectedClassFromAllLayers();

  layerElement.classList.add(
    "is-selected"
  );

  const bounds =
    calculateLayerScreenBounds(
      layerElement
    );

  editorState.selectionBounds =
    bounds;

  renderSelectionOverlay({
    layerId,
    layerType,
    bounds
  });

  renderTopToolbar({
    layerId,
    layerType
  });

  renderContextualToolbar({
    layerId,
    layerType,
    bounds
  });
}

7. TÍNH BOUNDING BOX CỦA LAYER
======================================================================

Với DOM layer:

function calculateLayerScreenBounds(
  layerElement
) {
  const rect =
    layerElement.getBoundingClientRect();

  return {
    left: rect.left,
    top: rect.top,
    right: rect.right,
    bottom: rect.bottom,
    width: rect.width,
    height: rect.height,
    centerX:
      rect.left + rect.width / 2,
    centerY:
      rect.top + rect.height / 2
  };
}

Nếu canvas có zoom hoặc pan, cần chuyển đổi tọa độ:

function canvasToScreen(point) {
  return {
    x:
      canvasViewportLeft +
      canvasPanX +
      point.x * canvasZoom,

    y:
      canvasViewportTop +
      canvasPanY +
      point.y * canvasZoom
  };
}

Nếu layer có rotation, không được chỉ sử dụng x, y, width, height gốc.

Phải tính transformed bounding box hoặc dùng getBoundingClientRect() nếu layer được render bằng DOM transform.


======================================================================
8. SELECTION OVERLAY
======================================================================

Selection overlay nên được render tách biệt với layer để:

- Không làm thay đổi kích thước thật của layer.
- Không ảnh hưởng nội dung text.
- Không nằm trong ảnh export.
- Không làm lệch layout.
- Dễ kiểm soát resize handle.
- Dễ thay đổi theo từng loại layer.

Ví dụ:

function renderSelectionOverlay({
  layerId,
  layerType,
  bounds
}) {
  const overlay =
    document.getElementById(
      "selection-overlay"
    );

  overlay.dataset.targetLayerId =
    layerId;

  overlay.dataset.targetLayerType =
    layerType;

  overlay.className =
    `selection-overlay selection-${layerType}`;

  positionOverlay(overlay, bounds);

  if (layerType === "text") {
    renderTextSelectionHandles(
      overlay
    );
  }

  if (layerType === "image") {
    renderImageSelectionHandles(
      overlay
    );
  }
}

11. CONTEXTUAL FLOATING TOOLBAR
======================================================================

Contextual floating toolbar xuất hiện gần layer được chọn.

Toolbar được render bằng Portal vào document.body để không bị ảnh hưởng bởi:

- overflow: hidden.
- transform.
- stacking context.
- canvas zoom.
- canvas clipping.

Ví dụ React:

createPortal(
  <ContextualToolbar />,
  document.body
);

Hoặc JavaScript thuần:

const toolbarRoot =
  document.getElementById(
    "contextual-toolbar-root"
  );

toolbarRoot.appendChild(
  toolbarElement
);

Toolbar nên có:

position: fixed;
z-index: 100000;

Không đặt toolbar trực tiếp bên trong layer.


======================================================================
12. TÍNH VỊ TRÍ FLOATING TOOLBAR
======================================================================

Toolbar ưu tiên nằm phía trên layer.

function calculateToolbarPosition({
  bounds,
  toolbarWidth,
  toolbarHeight
}) {
  const gap = 10;
  const safeMargin = 8;

  let left =
    bounds.centerX -
    toolbarWidth / 2;

  let top =
    bounds.top -
    toolbarHeight -
    gap;

  if (top < safeMargin) {
    top =
      bounds.bottom +
      gap;
  }

  if (
    left + toolbarWidth >
    window.innerWidth -
    safeMargin
  ) {
    left =
      window.innerWidth -
      toolbarWidth -
      safeMargin;
  }

  if (left < safeMargin) {
    left = safeMargin;
  }

  return {
    left,
    top
  };
}

Toolbar phải được tính lại khi:

- Layer di chuyển.
- Layer resize.
- Canvas zoom.
- Canvas pan.
- Window resize.
- Viewport scroll.
- Thay đổi loại layer.
- Chọn layer khác.

15. HÀM CHỌN MENU THEO LOẠI LAYER

function getFloatingMenuByLayerType(
  layerType
) {
  switch (layerType) {
    case "text":
      return textFloatingMenu;

    case "image":
      return imageFloatingMenu;

    default:
      return defaultFloatingMenu;
  }
}

function renderContextualToolbar({
  layerId,
  layerType,
  bounds
}) {
  const menuItems =
    getFloatingMenuByLayerType(
      layerType
    );

  contextualToolbarStore.open({
    targetLayerId: layerId,
    layerType,
    menuItems,
    bounds
  });
}

function duplicateLayer(layerId) {
  const source =
    documentStore.getLayer(layerId);

  const duplicated =
    structuredClone(source);

  duplicated.id =
    generateLayerId();

  duplicated.x += 12;
  duplicated.y += 12;

  documentStore.insertLayerAfter(
    layerId,
    duplicated
  );

  selectLayerById(
    duplicated.id
  );

  history.push({
    type: "DUPLICATE_LAYER",
    sourceLayerId: layerId,
    duplicatedLayerId:
      duplicated.id
  });
}

function deleteLayer(layerId) {

function createToolbarButton(item) {
  const button =
    document.createElement("button");

  button.type = "button";
  button.dataset.actionId = item.id;
  button.setAttribute(
    "aria-label",
    item.label
  );

  button.innerHTML =
    renderIcon(item.icon);

  button.addEventListener(
    "pointerdown",
    event => {
      event.preventDefault();
      event.stopPropagation();
    }
  );

  button.addEventListener(
    "click",
    event => {
      event.preventDefault();
      event.stopPropagation();

      item.action(
        editorState.primaryLayerId
      );
    }
  );

  return button;
}

function buildContextualToolbar(
  menuItems
) {
  const toolbar =
    document.createElement("div");

  toolbar.className =
    "contextual-toolbar";

  toolbar.setAttribute(
    "role",
    "toolbar"
  );

  menuItems.forEach(item => {
    toolbar.appendChild(
      createToolbarButton(item)
    );
  });

  return toolbar;
}

36. PSEUDOCODE TỔNG HỢP
======================================================================

function handleCanvasPointerDown(event) {
  if (
    event.button !== 0
  ) {
    return;
  }

  if (
    event.target.closest(
      ".contextual-toolbar"
    )
  ) {
    return;
  }

  if (
    event.target.closest(
      ".selection-overlay"
    )
  ) {
    return;
  }

  const layerElement =
    event.target.closest(
      "[data-layer-id]"
    );

  if (!layerElement) {
    clearSelection();
    return;
  }

  const layerId =
    layerElement.dataset.layerId;

  const layerType =
    layerElement.dataset.layerType;

  const layer =
    documentStore.getLayer(
      layerId
    );

  if (!layer) {
    clearSelection();
    return;
  }

  selectionStore.selectOnly(
    layerId
  );

  renderSelectionOverlay({
    layerId,
    layerType,
    bounds:
      calculateLayerScreenBounds(
        layerElement
      )
  });

  renderTopToolbar({
    layerId,
    layerType
  });

  renderContextualToolbar({
    layerId,
    layerType,
    bounds:
      calculateLayerScreenBounds(
        layerElement
      )
  });
}


function renderContextualToolbar({
  layerId,
  layerType,
  bounds
}) {
  const menuItems =
    getFloatingMenuByLayerType(
      layerType
    );

  const toolbar =
    buildContextualToolbar(
      menuItems
    );

  document.body.appendChild(
    toolbar
  );

  const toolbarRect =
    toolbar.getBoundingClientRect();

  const position =
    calculateToolbarPosition({
      bounds,
      toolbarWidth:
        toolbarRect.width,
      toolbarHeight:
        toolbarRect.height
    });

  toolbar.style.left =
    `${position.left}px`;

  toolbar.style.top =
    `${position.top}px`;

  toolbar.dataset.targetLayerId =
    layerId;

  toolbar.dataset.layerType =
    layerType;
}
