======================================================================
1. MỤC TIÊU
======================================================================

Xây dựng hệ thống chọn màu giống Canva cho trình thiết kế web.

Khi người dùng click vào một layer trên canvas như:

- Text layer
- Image layer
- Shape layer
- Frame layer
- HTML layer
- SVG element layer
- Group layer
- Component layer

Hệ thống phải:

1. Chọn đúng layer trên canvas.
2. Hiển thị contextual toolbar của layer.
3. Phân tích layer đó đang có bao nhiêu màu có thể chỉnh.
4. Hiển thị bấy nhiêu ô màu trên context menu hoặc top toolbar.
5. Tất cả ô màu phải là hình tròn.
6. Click vào từng ô màu sẽ mở sidebar chọn màu.
7. Sidebar màu hiển thị:
   - Màu cơ bản.
   - Màu có trong thiết kế.
   - Màu đang có trong các layer.
   - Màu của layer đang click.
   - Màu gradient.
   - Bộ màu thương hiệu nếu có.
   - Ô tìm màu bằng tên hoặc mã HEX.
8. Khi chọn màu xong:
   - Màu được áp dụng ngay vào đúng color slot của layer.
   - Ô màu trên toolbar đổi sang màu vừa chọn.
   - Sidebar vẫn có thể giữ mở để chọn tiếp.
9. Nếu click lại vào ô màu đã chọn:
   - Mở lại sidebar màu.
   - Focus đúng color slot đang chỉnh.
10. Nếu click vào màu đang chọn trong sidebar:
   - Mở bảng màu canvas/custom color picker cho ô màu đó.
11. Nếu màu là gradient:
   - Cho phép chỉnh lại từng màu trong gradient.
   - Cho phép thêm/xóa color stop.
   - Cho phép đổi hướng gradient.
   - Cho phép đổi kiểu gradient.
12. Mọi thay đổi màu phải hỗ trợ Undo/Redo.

2. KHÁI NIỆM COLOR SLOT
======================================================================

Color slot là một vị trí màu có thể chỉnh sửa của một layer.

Ví dụ text layer có thể có:

- textFill
- textStroke
- textBackground
- textShadowColor

Ví dụ shape layer có thể có:

- fill
- stroke
- shadowColor
- gradientStop1
- gradientStop2

Ví dụ HTML layer có thể có nhiều màu:

- color
- background-color
- border-color
- box-shadow color
- SVG fill bên trong
- CSS variable màu

Ví dụ SVG element có thể có:

- path fill 1
- path fill 2
- path stroke 1
- gradient stop 1
- gradient stop 2

Nếu layer có 3 màu thì toolbar hiện 3 ô màu tròn.
Nếu layer có 4 màu thì toolbar hiện 4 ô màu tròn.
Nếu layer có 10 màu thì toolbar hiện 10 ô màu tròn hoặc gom vào nút "More colors" nếu quá nhiều.

Mỗi color slot cần có cấu trúc dữ liệu:

type ColorSlot = {

};

function handleCanvasPointerDown(event) {
  const layerElement = event.target.closest("[data-layer-id]");

  if (!layerElement) {
    clearSelection();
    closeColorSidebar();
    return;
  }

  event.preventDefault();
  event.stopPropagation();

  const layerId = layerElement.dataset.layerId;
  const layerType = layerElement.dataset.layerType;

  selectLayerAndShowColorSlots({
    layerId,
    layerType,
    layerElement
  });
}

function selectLayerAndShowColorSlots({
  layerId,
  layerType,
  layerElement
}) {
  closeTransientMenusExceptColorSidebarIfPinned();

  selectionStore.selectOnly(layerId);

  const bounds = calculateLayerScreenBounds(layerElement);

  const colorSlots = extractEditableColorSlots({
    layerId,
    layerType
  });

  contextualToolbarStore.open({
    targetLayerId: layerId,
    layerType,
    bounds,
    colorSlots
  });

  renderSelectionOverlay({
    layerId,
    layerType,
    bounds
  });

  renderLayerContextualToolbar({
    layerId,
    layerType,
    bounds,
    colorSlots
  });

  renderTopToolbarByLayerType({
    layerId,
    layerType,
    colorSlots
  });
}

function extractEditableColorSlots({
  layerId,
  layerType
}) {
  const layer = documentStore.getLayer(layerId);

  switch (layerType) {
    case "text":
      return extractTextColorSlots(layer);

    case "image":
      return extractImageColorSlots(layer);

    case "shape":
      return extractShapeColorSlots(layer);

    case "frame":
      return extractFrameColorSlots(layer);

    case "html":
      return extractHtmlColorSlots(layer);

    case "svg":
      return extractSvgColorSlots(layer);

    case "group":
      return extractGroupColorSlots(layer);

    default:
      return [];
  }
}

function extractTextColorSlots(layer) {
  const slots = [];

  if (layer.style.color) {
    slots.push({
      id: `${layer.id}:text-fill`,
      layerId: layer.id,
      slotKey: "textFill",
      label: "Text color",

      editable: true,
      visible: true,
      source: "text",
      cssProperty: "color",
      applyMode: "replace-css-property"
    });
  }

  if (layer.style.webkitTextStrokeColor) {
    slots.push({
      id: `${layer.id}:text-stroke`,
      layerId: layer.id,
      slotKey: "textStroke",
      label: "Text stroke",
      value: normalizeColor(layer.style.webkitTextStrokeColor),
      editable: true,
      visible: true,
      source: "text",
      cssProperty: "-webkit-text-stroke-color",
      applyMode: "replace-css-property"
    });
  }

  if (layer.style.backgroundColor) {
    slots.push({
      id: `${layer.id}:text-background`,
      layerId: layer.id,
      slotKey: "textBackground",
      label: "Text background",
      value: normalizeColor(layer.style.backgroundColor),
      editable: true,
      visible: true,
      source: "text",
      cssProperty: "background-color",
      applyMode: "replace-css-property"
    });
  }

  if (layer.style.shadowColor) {
    slots.push({

      editable: true,
      visible: true,
      source: "text",

      value: normalizeColor(layer.shadow.color),
      editable: true,
      visible: true,
      source: "shape",
      applyMode: "replace-solid"

11. HTML LAYER COLOR SLOTS
======================================================================

HTML layer có thể chứa nhiều CSS màu.

Cần parse:

- Inline style
- CSS variables
- style tag
- computed style
- SVG bên trong HTML
- background
- border
- box-shadow
- color
- fill
- stroke

function extractHtmlColorSlots(layer) {
  const html = layer.html;
  const root = parseHtmlToVirtualDom(html);

  const colorEntries = [];

  walkHtmlNodes(root, node => {
    const styles = extractNodeStyles(node);

    for (const [property, value] of Object.entries(styles)) {
      if (isColorValue(value)) {
        colorEntries.push({
          nodeId: node.dataset?.nodeId || generateNodePath(node),
          property,
          value
        });
      }

      if (isGradientValue(value)) {
        colorEntries.push({
          nodeId: node.dataset?.nodeId || generateNodePath(node),
          property,
          value: parseGradient(value)
        });
      }
    }
  });

  return colorEntries.map((entry, index) => ({
    id: `${layer.id}:html-color-${index}`,
    layerId: layer.id,
    slotKey: `htmlColor.${index}`,
    label: `${entry.property}`,
    value: normalizeColorValue(entry.value),
    editable: true,
    visible: true,
    source: "html",
    cssProperty: entry.property,
    path: entry.nodeId,
    applyMode: "replace-html-style"
  }));
}

Khi HTML layer có 3 màu thì toolbar hiện 3 ô màu.
Khi HTML layer có 4 màu thì toolbar hiện 4 ô màu.
Khi HTML layer có nhiều hơn 8 màu thì có thể hiện 8 ô đầu + nút More.

12. SVG ELEMENT COLOR SLOTS
======================================================================

SVG element có thể có nhiều path và nhiều màu.

Cần parse:

- fill
- stroke
- stop-color
- gradient
- CSS style trong SVG
- currentColor nếu có

function extractSvgColorSlots(layer) {
  const svgRoot = parseSvg(layer.svg);

  const slots = [];

  walkSvgNodes(svgRoot, node => {
    const nodeId = node.getAttribute("id") || generateSvgNodePath(node);

    const fill = node.getAttribute("fill");
    const stroke = node.getAttribute("stroke");

    if (isColorValue(fill)) {
      slots.push({
        id: `${layer.id}:${nodeId}:fill`,
        layerId: layer.id,
        slotKey: `svg.${nodeId}.fill`,
        label: "SVG fill",
        value: normalizeColor(fill),
        editable: true,
        visible: true,
        source: "svg",
        svgPathId: nodeId,
        applyMode: "replace-svg-fill"
      });
    }

    if (isColorValue(stroke)) {
      slots.push({
        id: `${layer.id}:${nodeId}:stroke`,
        layerId: layer.id,
        slotKey: `svg.${nodeId}.stroke`,
        label: "SVG stroke",
        value: normalizeColor(stroke),
        editable: true,
        visible: true,
        source: "svg",
        svgPathId: nodeId,
        applyMode: "replace-svg-stroke"
      });
    }
  });

  return expandGradientSlots(slots);
}

function extractGroupColorSlots(groupLayer) {
  const childLayers = getAllChildren(groupLayer.id);

  const allSlots = [];

  childLayers.forEach(child => {
    const childSlots = extractEditableColorSlots({
      layerId: child.id,
      layerType: child.type
    });

    allSlots.push(...childSlots);
  });

  return mergeDuplicateColorSlots(allSlots);
}

Ví dụ group có 5 layer nhưng chỉ có 3 màu khác nhau thì context toolbar có thể hiện 3 ô màu.

- Hoặc chỉ đổi slot đại diện nếu người dùng chọn chi tiết trong sidebar.

Ví dụ render toolbar:

function renderColorSlotsInToolbar(colorSlots) {
  const container = document.createElement("div");
  container.className = "toolbar-color-slots";

  colorSlots.forEach(slot => {
    const chip = createColorChip(slot);

    container.appendChild(chip);
  });

  return container;
}

function createColorChip(slot) {
  const button = document.createElement("button");

  button.className = "color-chip";
  button.dataset.colorSlotId = slot.id;
  button.title = slot.label;
  button.setAttribute("aria-label", slot.label);

  applyColorChipBackground(button, slot.value);

  button.addEventListener("pointerdown", event => {
    event.preventDefault();
    event.stopPropagation();
  });

  button.addEventListener("click", event => {
    handleColorChipClick(event, slot.id);
  });

  return button;
}

Nếu layer có nhiều màu:

- 1 màu: hiển thị 1 ô tròn.
- 2 màu: hiển thị 2 ô tròn.
- 3 màu: hiển thị 3 ô tròn.
- 4 màu: hiển thị 4 ô tròn.
- Nhiều hơn 8 màu: hiển thị 8 ô đầu + nút More Colors.

Nút More Colors cũng là hình tròn hoặc dạng icon tròn.

function applyColorChipBackground(element, colorValue) {
  if (colorValue.type === "solid") {
    element.style.background = colorToCss(colorValue);
    element.classList.remove("color-chip-gradient");
    return;
  }

  if (colorValue.type === "gradient") {
    element.style.background = gradientToCss(colorValue);
    element.classList.add("color-chip-gradient");
    return;
  }
}

function colorToCss(color) {
  return `rgba(${color.rgb.r}, ${color.rgb.g}, ${color.rgb.b}, ${color.alpha})`;
}

function gradientToCss(gradient) {
  const stops = gradient.stops
    .map(stop => {
      return `${colorToCss(stop.color)} ${stop.position}%`;
    })
    .join(", ");

  if (gradient.gradientType === "linear") {
    return `linear-gradient(${gradient.angle}deg, ${stops})`;
  }

  if (gradient.gradientType === "radial") {
    return `radial-gradient(circle, ${stops})`;
  }

  if (gradient.gradientType === "conic") {
    return `conic-gradient(from ${gradient.angle}deg, ${stops})`;
  }
}

function analyzeColorsInDesign(document) {
  const colorMap = new Map();

  document.pages.forEach(page => {
    page.layers.forEach(layer => {
      const slots = extractEditableColorSlots({
        layerId: layer.id,
        layerType: layer.type
      });

      slots.forEach(slot => {
        collectColorValue(colorMap, slot.value, {
          layerId: layer.id,
          pageId: page.id,
          slotId: slot.id
        });
      });
    });
  });

  return Array.from(colorMap.values())
    .sort((a, b) => b.count - a.count);
}

function collectColorValue(colorMap, colorValue, meta) {
  if (colorValue.type === "solid") {
    addSolidColorToMap(colorMap, colorValue, meta);
    return;
  }

  if (colorValue.type === "gradient") {
    colorValue.stops.forEach(stop => {
      addSolidColorToMap(colorMap, stop.color, meta);
    });
  }
}

function addSolidColorToMap(colorMap, color, meta) {
  const key = normalizeHex(color.hex);

  if (!colorMap.has(key)) {
    colorMap.set(key, {
      color,
      count: 0,
      usedBy: []
    });
  }

  const item = colorMap.get(key);

  item.count += 1;
  item.usedBy.push(meta);
}

function getColorsFromLayer(layer) {
  const slots = extractEditableColorSlots({
    layerId: layer.id,
    layerType: layer.type
  });

  const colors = [];

  slots.forEach(slot => {
    if (slot.value.type === "solid") {
      colors.push({
        label: slot.label,
        color: slot.value,
        sourceSlotId: slot.id
      });
    }

    if (slot.value.type === "gradient") {
      slot.value.stops.forEach(stop => {
        colors.push({
          label: `${slot.label} stop ${stop.position}%`,
          color: stop.color,
          sourceSlotId: slot.id,
          gradientStopId: stop.id
        });
      });
    }
  });

  return dedupeColors(colors);
}

function applyColorToSlot({
  slot,
  colorValue,
  commitToHistory
}) {
  const layer = documentStore.getLayer(slot.layerId);

  if (!layer || !slot.editable) {
    return;
  }

  const before = cloneLayer(layer);

  switch (slot.applyMode) {
    case "replace-solid":
      applySolidColor(layer, slot, colorValue);
      break;

    case "replace-css-property":
      applyCssPropertyColor(layer, slot, colorValue);
      break;

    case "replace-html-style":
      applyHtmlStyleColor(layer, slot, colorValue);
      break;

    case "replace-svg-fill":
      applySvgFillColor(layer, slot, colorValue);
      break;

    case "replace-svg-stroke":
      applySvgStrokeColor(layer, slot, colorValue);
      break;

    case "replace-gradient-stop":
      applyGradientColor(layer, slot, colorValue);
      break;

    case "replace-image-filter":
      applyImageFilterColor(layer, slot, colorValue);
      break;
  }

  documentStore.updateLayer(layer.id, layer);

  rerenderLayer(layer.id);

  refreshToolbarColorSlots(layer.id);

  if (commitToHistory) {
    history.push({
      type: "CHANGE_LAYER_COLOR",
      layerId: layer.id,
      slotId: slot.id,
      before,
      after: cloneLayer(layer)
    });
  }
}

function applyHtmlStyleColor(layer, slot, colorValue) {
  const root = parseHtmlToVirtualDom(layer.html);

  const targetNode = findHtmlNodeByPath(root, slot.path);

  if (!targetNode) {
    return;
  }

  const cssValue =
    colorValue.type === "solid"
      ? colorToCss(colorValue)
      : gradientToCss(colorValue);

  targetNode.style[slot.cssProperty] = cssValue;

  layer.html = serializeHtml(root);
}

function applySvgFillColor(layer, slot, colorValue) {

}

function applyGradientColor(layer, slot, colorValue) {
  if (colorValue.type === "gradient") {
    layer[slot.slotKey] = colorValue;
    return;
  }

  const currentValue = getLayerSlotValue(layer, slot);

  if (currentValue.type === "gradient") {
    const activeStopId =
      colorSidebarStore.state.gradientEditor.activeStopId;

    const stop = currentValue.stops.find(
      item => item.id === activeStopId
    );

    if (stop) {
      stop.color = colorValue;
    }

    layer[slot.slotKey] = currentValue;
    return;
  }

  layer[slot.slotKey] = colorValue;
}

    layer.duotone.lightColor = color;
  }

  if (slot.slotKey === "imageOverlay") {
    layer.overlay.color = color;
  }
}

function flattenColorValue(colorValue) {
  if (!colorValue) {
    return [];
  }

  if (colorValue.type === "solid") {
    return [colorValue];
  }

  if (colorValue.type === "gradient") {
    return colorValue.stops.map(stop => stop.color);
  }

  return [];
}

50. DEDUPE COLORS
======================================================================

function dedupeColors(colors) {
  const map = new Map();

  colors.forEach(item => {
    const color = item.color || item;
    const key = normalizeHex(color.hex);

    if (!map.has(key)) {
      map.set(key, {
        color,
        count: 0,
        sources: []
      });
    }

    const existing = map.get(key);

    existing.count += 1;

    if (item.layerId || item.sourceSlotId) {
      existing.sources.push(item);
    }
  });

  return Array.from(map.values())
    .sort((a, b) => b.count - a.count);
}

Nếu cần lấy màu từ ảnh raster trong layer image:

async function extractDominantColorsFromImage({
  imageBitmap,
  maxColors,
  sampleSize
}) {
  const canvas = new OffscreenCanvas(
    sampleSize,
    sampleSize
  );

  const ctx = canvas.getContext("2d");

  ctx.drawImage(
    imageBitmap,
    0,
    0,
    sampleSize,
    sampleSize
  );

  const imageData = ctx.getImageData(
    0,
    0,
    sampleSize,
    sampleSize
  );

  const pixels = imageData.data;

  const buckets = new Map();

  for (let i = 0; i < pixels.length; i += 4) {
    const r = quantize(pixels[i], 16);
    const g = quantize(pixels[i + 1], 16);
    const b = quantize(pixels[i + 2], 16);
    const a = pixels[i + 3];

    if (a < 128) {
      continue;
    }

    const key = `${r},${g},${b}`;

    buckets.set(
      key,
      (buckets.get(key) || 0) + 1
    );
  }

  return Array.from(buckets.entries())
    .sort((a, b) => b[1] - a[1])
    .slice(0, maxColors)
    .map(([key]) => {
      const [r, g, b] = key
        .split(",")
        .map(Number);

      return {
        type: "solid",
        hex: rgbToHex(r, g, b),
        rgb: { r, g, b },
        alpha: 1
      };
    });
}

function quantize(value, step) {
  return Math.round(value / step) * step;
}

class ChangeColorCommand {
  constructor({
    layerId,
    slotId,
    before,
    after
  }) {
    this.layerId = layerId;
    this.slotId = slotId;
    this.before = before;
    this.after = after;
  }

  execute() {
    documentStore.updateLayer(
      this.layerId,
      this.after
    );

    rerenderLayer(this.layerId);
    refreshToolbarColorSlots(this.layerId);
  }

  undo() {
    documentStore.updateLayer(
      this.layerId,
      this.before
    );

    rerenderLayer(this.layerId);
    refreshToolbarColorSlots(this.layerId);
  }

  redo() {
    this.execute();
  }
}

function isColorValue(value) {
  if (!value) {
    return false;
  }

  return (
    /^#([0-9a-f]{3}|[0-9a-f]{6}|[0-9a-f]{8})$/i.test(value) ||
    /^rgb\(/i.test(value) ||
    /^rgba\(/i.test(value) ||
    /^hsl\(/i.test(value) ||
    /^hsla\(/i.test(value) ||
    isNamedColor(value)
  );
}

function isGradientValue(value) {
  if (!value) {
    return false;
  }

  return (
    value.includes("linear-gradient") ||
    value.includes("radial-gradient") ||
    value.includes("conic-gradient")
  );
}

function normalizeColor(value) {
  if (typeof value === "string") {
    const rgb = parseCssColorToRgb(value);

    return {
      type: "solid",
      hex: rgbToHex(rgb.r, rgb.g, rgb.b),
      rgb: {
        r: rgb.r,
        g: rgb.g,
        b: rgb.b
      },
      alpha: rgb.a ?? 1
    };
  }

  return value;
}

function normalizeColorValue(value) {
  if (isGradientValue(value)) {
    return parseGradient(value);
  }

  return normalizeColor(value);
}
