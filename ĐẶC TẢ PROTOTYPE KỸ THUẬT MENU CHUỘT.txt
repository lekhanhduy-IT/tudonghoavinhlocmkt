======================================================================
1. MỤC TIÊU
======================================================================

Xây dựng một context-sensitive layer action menu tương tự menu chuột phải của Canva.

Menu được hiển thị khi người dùng nhấn chuột phải vào một layer trong vùng thiết kế và cung cấp các chức năng:

1. Copy
2. Copy style
3. Paste
4. Duplicate
5. Delete
6. Layer
7. Align to page
8. Ungroup
9. Create component
10. Comment
11. Lock
12. Show element timings
13. Download selection

Nội dung menu, trạng thái disabled, submenu và phím tắt phải được tạo động dựa trên:

- Loại layer.
- Số lượng layer đang chọn.
- Trạng thái khóa.
- Loại tài liệu.
- Quyền chỉnh sửa của người dùng.
- Dữ liệu clipboard.
- Trạng thái timeline.
- Cấu trúc group hoặc component.
- Vị trí của layer trong z-order.


======================================================================
2. BẮT SỰ KIỆN CHUỘT PHẢI TRÊN LAYER
======================================================================

Mỗi layer cần đăng ký sự kiện contextmenu.

Ví dụ:

layerElement.addEventListener("contextmenu", handleLayerContextMenu);

Khi người dùng nhấn chuột phải vào layer:

function handleLayerContextMenu(event, layerId) {
  event.preventDefault();
  event.stopPropagation();

  selectLayer(layerId);

  openContextMenu({
    targetType: "layer",
    targetId: layerId,
    x: event.clientX,
    y: event.clientY
  });
}

Hệ thống thực hiện theo thứ tự:

1. Gọi event.preventDefault() để chặn menu chuột phải mặc định của trình duyệt.
2. Gọi event.stopPropagation() để ngăn sự kiện truyền lên page wrapper hoặc canvas container.
3. Thực hiện hit-test để xác định chính xác layer nằm dưới con trỏ.
4. Kiểm tra quyền tương tác với layer.
5. Cập nhật selection state.
6. Hiển thị bounding box của layer.
7. Hiển thị resize handles.
8. Hiển thị rotation handle nếu layer cho phép xoay.
9. Hiển thị floating contextual toolbar phía trên layer.
10. Ghi nhận tọa độ con trỏ bằng clientX và clientY.
11. Cập nhật context menu state.
12. Mount context menu bằng Portal vào document.body.
13. Chạy thuật toán collision detection.
14. Điều chỉnh vị trí menu nếu menu vượt ra ngoài viewport.

Nếu layer chưa được chọn, thao tác chuột phải phải chọn layer trước khi mở menu.

Nếu chuột phải vào một layer khác trong khi menu đang mở:

1. Đóng menu hiện tại.
2. Bỏ chọn layer cũ.
3. Chọn layer mới.
4. Tính lại bounding box.
5. Mở menu mới tại vị trí con trỏ.
6. Tạo lại danh sách action dựa trên layer mới.


======================================================================
3. HIT-TEST VÀ XÁC ĐỊNH TARGET
======================================================================

Nếu trình chỉnh sửa sử dụng HTML DOM, target có thể được xác định qua dataset:

const layerElement = event.target.closest("[data-layer-id]");
const layerId = layerElement?.dataset.layerId;

Nếu sử dụng Canvas 2D hoặc WebGL, cần thực hiện hit-test theo tọa độ canvas:

const canvasPoint = screenToCanvas({
  x: event.clientX,
  y: event.clientY
});

const targetLayer = hitTestLayerTree(canvasPoint);

Quy trình hit-test nên xét:

- Vị trí.
- Kích thước.
- Rotation.
- Transformation matrix.
- Mask.
- Clip path.
- Opacity.
- Z-order.
- Layer visibility.
- Pointer events.
- Group hierarchy.

Khi nhiều layer chồng lên nhau, hệ thống chọn layer có z-index cao nhất nằm tại vị trí con trỏ.

Có thể hỗ trợ cơ chế chọn layer nằm phía dưới bằng Alt + chuột phải hoặc menu Select layer.

Ví dụ:

const selectionState = {
  selectedIds: ["layer-123"],
  primaryId: "layer-123",
  selectionType: "group",
  bounds: {
    x: 120,
    y: 80,
    width: 420,
    height: 580
  }
};

Các loại selection có thể gồm:

- none
- single
- multi
- group
- component
- component-instance
- text
- image
- video
- shape
- audio
- frame
- locked-layer

Khi người dùng chuột phải vào layer đang nằm trong multi-selection:

- Nếu layer thuộc vùng chọn hiện tại thì giữ nguyên toàn bộ selection.
- Nếu layer không thuộc vùng chọn hiện tại thì bỏ selection cũ và chọn layer mới.


======================================================================
5. STATE CỦA CONTEXT MENU
======================================================================

Ví dụ:

const contextMenuState = {
  isOpen: true,
  targetType: "layer",
  targetId: "layer-123",
  anchorX: 420,
  anchorY: 260,
  menuX: 420,
  menuY: 260,
  activeSubmenu: null,
  focusedItemId: "copy"
};

Các thuộc tính chính:

- isOpen: trạng thái mở hoặc đóng.
- targetType: loại đối tượng được mở menu.
- targetId: ID của layer hoặc group.
- anchorX: tọa độ X của con trỏ.
- anchorY: tọa độ Y của con trỏ.
- menuX: vị trí X sau collision detection.
- menuY: vị trí Y sau collision detection.
- activeSubmenu: submenu đang mở.
- focusedItemId: item đang nhận keyboard focus.


======================================================================
6. RENDER CONTEXT MENU BẰNG PORTAL
======================================================================

Context menu nên được mount ngoài vùng canvas bằng Portal để tránh:

- overflow: hidden.
- CSS clipping.
- stacking context.
- transform của canvas.
- scale của canvas.
- z-index của layer.
- scroll container.
- filter hoặc perspective của ancestor.

Ví dụ React:

createPortal(
  <LayerContextMenu />,
  document.body
);

CSS cơ bản:

.context-menu {
  position: fixed;
  z-index: 99999;
  min-width: 372px;
  max-height: calc(100vh - 16px);
  overflow-y: auto;
  background: #ffffff;
  border: 1px solid rgba(0, 0, 0, 0.08);
  box-shadow: 0 8px 32px rgba(0, 0, 0, 0.16);
}

Mỗi hàng trong menu gồm:

- Icon bên trái.
- Label ở giữa.
- Shortcut badge hoặc submenu arrow bên phải.
- Hover state.
- Focus state.
- Disabled state.
- Checked state.
- Dangerous state.


======================================================================
7. COLLISION DETECTION
======================================================================

Menu không được vượt ra ngoài viewport.

Ví dụ:

const safeMargin = 8;

const menuX = Math.min(
  pointerX,
  window.innerWidth - menuWidth - safeMargin
);

const menuY = Math.min(
  pointerY,
  window.innerHeight - menuHeight - safeMargin
);

Nếu pointerX hoặc pointerY nhỏ hơn safeMargin:

menuX = Math.max(menuX, safeMargin);
menuY = Math.max(menuY, safeMargin);

Nếu submenu không đủ khoảng trống bên phải:

const openDirection =
  menuRight + submenuWidth > viewportWidth
    ? "left"
    : "right";

Nếu menu quá cao:

- Giới hạn max-height.
- Bật overflow-y: auto.
- Không làm thay đổi kích thước canvas.
- Có thể ẩn scrollbar nhưng vẫn cho phép cuộn.

const menuItems = [

    icon: "clipboard",
    disabled: !clipboardState.hasSupportedContent,
    action: pasteClipboard
  },
  {
    id: "duplicate",
    label: "Duplicate",
    shortcut: "Ctrl+D",
    icon: "duplicate",

  {

Interface đề xuất:

interface ContextMenuItem {
  id?: string;
  type?: "item" | "separator";
  label?: string;
  icon?: string;
  shortcut?: string;
  visible?: boolean;
  disabled?: boolean;
  dangerous?: boolean;
  checked?: boolean;
  action?: () => void;
  submenu?: ContextMenuItem[];
}

10. COPY
======================================================================

Khi người dùng click Copy hoặc nhấn Ctrl + C:

dispatch({
  type: "COPY_SELECTION",
  payload: {
    layerIds: selectionState.selectedIds
  }
});

Hệ thống serialize toàn bộ layer đang chọn:

const clipboardPayload = {
  type: "design-layer",
  version: 1,
  sourceDocumentId: currentDocumentId,
  sourcePageId: currentPageId,
  layers: selectedLayers.map(serializeLayer),
  boundingBox: calculateSelectionBounds(selectedLayers)
};

Dữ liệu cần giữ:

- Layer type.
- Nội dung text.
- Image source.
- Video source.
- Audio source.
- Tọa độ.
- Width.
- Height.
- Rotation.
- Transform matrix.
- Opacity.
- Fill.
- Stroke.
- Effects.
- Filters.
- Crop.
- Mask.
- Animation.
- Timing.
- Group hierarchy.
- Component references.
- Z-order tương đối.
- Lock state nếu phù hợp.

Clipboard có thể lưu tại:

- Internal application store.
- navigator.clipboard.
- IndexedDB.
- In-memory cache.

Sau khi copy:

- Không thay đổi document model.
- Không tạo history entry.
- Đóng context menu.
- Giữ nguyên selection.
- Có thể hiển thị toast “Đã sao chép”.

11. COPY STYLE
======================================================================

Copy style chỉ sao chép presentation properties, không sao chép nội dung và geometry.

Ví dụ:

const copiedStyle = extractLayerStyle(selectedLayer);

Dữ liệu style có thể gồm:

{
  fill,
  stroke,
  strokeWidth,
  strokeStyle,
  fontFamily,
  fontSize,
  fontWeight,
  fontStyle,
  textDecoration,
  lineHeight,
  letterSpacing,
  textAlign,
  textTransform,
  opacity,
  borderRadius,
  shadow,
  filters,
  blendMode,
  effects
}

Không sao chép:

- id.
- Nội dung text.
- URL ảnh.
- URL video.
- Tọa độ.
- Width.
- Height.
- Group parent.
- Component ID.
- Timing.

Sau khi chọn Copy style:

editorMode = "paste-style";

Con trỏ có thể chuyển thành paint roller.

Khi người dùng click một layer khác:

applyStyle(targetLayerId, copiedStyle);

Thao tác apply style phải:

1. Kiểm tra style có tương thích với target hay không.
2. Chỉ áp dụng các thuộc tính được hỗ trợ.
3. Cập nhật document model.
4. Re-render layer.
5. Ghi một transaction vào undo history.
6. Thoát chế độ paste-style hoặc tiếp tục tùy thiết kế UX.


======================================================================
12. PASTE
======================================================================

Khi click Paste hoặc nhấn Ctrl + V:

1. Đọc clipboard nội bộ.
2. Đọc system clipboard nếu được cấp quyền.
3. Xác định MIME type.
4. Validate dữ liệu.
5. Clone dữ liệu.
6. Sinh ID mới.
7. Resolve reference.
8. Offset vị trí.
9. Insert vào document tree.
10. Cập nhật selection.
11. Push transaction vào history.
12. Re-render canvas.

Ví dụ:

dispatch({
  type: "PASTE_LAYERS",
  payload: {
    clipboardData,
    offset: {
      x: 16,
      y: 16
    }
  }
});

Hệ thống có thể hỗ trợ paste:

- Layer nội bộ.
- Text thuần.
- Rich text.
- HTML.
- SVG.
- PNG.
- JPEG.
- GIF.
- File.
- Image blob.
- URL.

Nếu clipboard không có dữ liệu phù hợp:

disabled: !clipboardState.hasSupportedContent;

Khi paste layer:

- Toàn bộ ID phải được tạo mới.
- Parent-child references phải được cập nhật.
- Component references phải được resolve.
- Bản sao được đặt phía trên layer hiện tại.
- Layer mới trở thành selection hiện tại.


======================================================================
13. DUPLICATE
======================================================================

Duplicate tạo bản sao trực tiếp mà không phụ thuộc system clipboard.

const duplicatedLayers = cloneLayers(selectedLayers, {
  regenerateIds: true,
  offsetX: 16,
  offsetY: 16
});

insertLayersAfterSelection(duplicatedLayers);

selectLayers(
  duplicatedLayers.map(layer => layer.id)
);

Yêu cầu:

- Sinh ID mới.
- Giữ nguyên group hierarchy.
- Giữ nguyên component relationship nếu phù hợp.
- Giữ nguyên thứ tự tương đối giữa các layer.
- Đặt bản sao lệch nhẹ sang phải và xuống dưới.
- Đặt bản sao ngay phía trên layer gốc trong layer tree.
- Bản sao trở thành selection mới.
- Toàn bộ thao tác là một history transaction duy nhất.

Ví dụ:

history.push({
  type: "DUPLICATE_LAYERS",
  before,
  after
});


======================================================================
14. DELETE
======================================================================

Khi chọn Delete:

dispatch({
  type: "DELETE_LAYERS",
  payload: {
    layerIds: selectionState.selectedIds
  }
});

Quy trình:

1. Kiểm tra quyền edit.
2. Kiểm tra lock state.
3. Kiểm tra dependency.
4. Xóa layer khỏi document tree.
5. Xóa hoặc cập nhật reference liên quan.
6. Xóa timeline track nếu cần.
7. Cập nhật component instance nếu cần.
8. Recalculate selection.
9. Re-render canvas.
10. Ghi undo history.
11. Đóng context menu.

Với layer khóa hoàn toàn:

disabled: selectedLayers.some(
  layer => layer.lockMode === "full"
);

Sau khi xóa:

- Có thể chọn layer liền kề.
- Hoặc bỏ chọn toàn bộ.
- Có thể hoàn tác bằng Ctrl + Z.

Delete có thể dùng dangerous state:

.context-menu-item[data-dangerous="true"]:hover {
  color: #d93025;
  background: rgba(217, 48, 37, 0.08);
}

setTimeout(() => {

======================================================================
16. BRING FORWARD
======================================================================

Đưa layer lên một cấp trong children array của cùng parent.

moveLayerInStack(
  layerId,
  currentIndex + 1
);

Yêu cầu:

- Không di chuyển layer ra khỏi group hiện tại.
- Không thay đổi parent.
- Cập nhật z-order.
- Giữ nguyên selection.
- Push history transaction.
- Disabled nếu layer đã nằm trên cùng.


======================================================================
17. BRING TO FRONT
======================================================================

Đưa layer lên trên cùng trong cùng parent container.

moveLayerToIndex(
  layerId,
  parent.children.length - 1
);

Nếu chọn nhiều layer:

- Giữ nguyên thứ tự tương đối của các layer.
- Đưa toàn bộ vùng chọn lên trên cùng.

Disabled nếu toàn bộ vùng chọn đã ở vị trí cao nhất.


======================================================================
18. SEND BACKWARD
======================================================================

Đưa layer xuống một cấp.

moveLayerInStack(
  layerId,
  currentIndex - 1
);

Disabled nếu layer đã ở index 0.


======================================================================
19. SEND TO BACK
======================================================================

Đưa layer xuống dưới cùng trong cùng parent container.

moveLayerToIndex(layerId, 0);

Nếu multi-selection:

- Giữ nguyên thứ tự tương đối.
- Đưa toàn bộ selection xuống dưới cùng.


======================================================================
20. SUBMENU ALIGN TO PAGE
======================================================================

Các lựa chọn:

- Align left.
- Align horizontal center.
- Align right.
- Align top.
- Align vertical center.
- Align bottom.

Page bounds:

const pageRect = {
  x: 0,
  y: 0,
  width: page.width,
  height: page.height
};

Layer bounds phải là transformed bounding box:

const layerBounds = getTransformedBoundingBox(layer);

Không nên dùng trực tiếp width và height gốc nếu layer có:

- Rotation.
- Scale.
- Skew.
- Mask.
- Nested transform.


======================================================================
21. ALIGN LEFT
======================================================================

newX = pageRect.x;

Nếu layer có rotation, tính delta dựa trên transformed bounding box:

const deltaX = pageRect.x - layerBounds.left;

applyTranslation(layerId, {
  x: deltaX,
  y: 0
});


======================================================================
22. ALIGN HORIZONTAL CENTER
======================================================================

const targetCenterX =
  pageRect.x + pageRect.width / 2;

const currentCenterX =
  layerBounds.left + layerBounds.width / 2;

const deltaX =
  targetCenterX - currentCenterX;

applyTranslation(layerId, {
  x: deltaX,
  y: 0
});


======================================================================
23. ALIGN RIGHT
======================================================================

const targetRight =
  pageRect.x + pageRect.width;

const deltaX =
  targetRight - layerBounds.right;

applyTranslation(layerId, {
  x: deltaX,
  y: 0
});


======================================================================
24. ALIGN TOP
======================================================================

const deltaY =
  pageRect.y - layerBounds.top;

applyTranslation(layerId, {
  x: 0,
  y: deltaY
});


======================================================================
25. ALIGN VERTICAL CENTER
======================================================================

const targetCenterY =
  pageRect.y + pageRect.height / 2;

const currentCenterY =
  layerBounds.top + layerBounds.height / 2;

const deltaY =
  targetCenterY - currentCenterY;

applyTranslation(layerId, {
  x: 0,
  y: deltaY
});


======================================================================
26. ALIGN BOTTOM
======================================================================

const targetBottom =
  pageRect.y + pageRect.height;

const deltaY =
  targetBottom - layerBounds.bottom;

applyTranslation(layerId, {
  x: 0,
  y: deltaY
});


======================================================================
27. ALIGN KHI MULTI-SELECTION
======================================================================

Khi chọn nhiều layer, mặc định căn selection bounding box theo page, không căn từng layer riêng lẻ.

const selectionBounds =
  calculateSelectionBounds(selectedLayers);

Sau khi tính delta:

selectedLayers.forEach(layer => {
  layer.x += deltaX;
  layer.y += deltaY;
});

Yêu cầu:

- Giữ nguyên khoảng cách tương đối giữa các layer.
- Giữ nguyên group hierarchy.
- Tạo một history transaction duy nhất.
- Giữ nguyên selection sau khi căn chỉnh.


======================================================================
28. UNGROUP
======================================================================

Ungroup chỉ hiển thị nếu target là group.

visible:
  selectedLayer.type === "group";

Khi nhấn Ungroup:

1. Lấy group.children.
2. Lấy parent của group.
3. Tính world transform của group.
4. Chuyển local transform của từng child thành transform trong hệ tọa độ của parent.
5. Di chuyển children ra parent.
6. Giữ nguyên z-order.
7. Xóa group container.
8. Chọn tất cả layer vừa tách.
9. Push history transaction.
10. Re-render canvas.

Ví dụ:

const worldMatrix = multiplyMatrices(
  parentWorldMatrix,
  group.transform
);

children.forEach(child => {
  child.transform = multiplyMatrices(
    worldMatrix,
    child.transform
  );
});

Nếu không xử lý transformation matrix, layer con có thể bị:

- Lệch vị trí.
- Sai rotation.
- Sai scale.

- Sai bounding box.

function handleLayerContextMenu(event, layerId) {
  event.preventDefault();
  event.stopPropagation();

  const layer = documentStore.getLayer(layerId);

  if (!layer) {
    return;
  }

  if (
    !selectionStore.selectedIds.includes(layerId)
  ) {
    selectionStore.selectOnly(layerId);
  }

  const menuItems = buildLayerContextMenu({
    selectedLayers:
      selectionStore.getSelectedLayers(),

    clipboardState:
      clipboardStore.getState(),

    permissions:
      permissionStore.getState(),

    documentType:
      documentStore.documentType
  });

  contextMenuStore.open({
    targetType: "layer",
    targetId: layerId,
    anchorX: event.clientX,
    anchorY: event.clientY,
    items: menuItems
  });
}


function executeContextMenuAction(actionId) {
  const context =
    createEditorActionContext();

  const action =
    actionRegistry.get(actionId);

  if (!action) {
    return;
  }

  if (!action.canExecute(context)) {
    showToast({
      type: "warning",
      message: "Không thể thực hiện thao tác này."
    });

    return;
  }

  try {
    history.beginTransaction(actionId);

    action.execute(context);

    history.commitTransaction();

    contextMenuStore.close();
  } catch (error) {
    history.rollbackTransaction();

    showToast({
      type: "error",
      message: getEditorErrorMessage(error)
    });
  }
}
